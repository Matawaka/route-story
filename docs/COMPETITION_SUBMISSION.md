## Текст для публикации

**Matawaka Route Story — v1.0.0**
Автор: **Dmitrii Olegovich Kuznetsov (Matawaka)**. Соло-разработка с использованием AI.

Приложение превращает GPX-трек в детерминированную анимированную видеоисторию маршрута с локальной обработкой и экспортом H.264 MP4 там, где браузер поддерживает кодирование.

Загрузить GPX → выбрать Atlas или Night → изменить название и длительность 10/20/30 секунд → посмотреть и перемотать replay → выбрать 9:16 или 16:9 → Export → открыть готовый видеофайл. Качество 360p/720p, 24 FPS; показаны расстояние и набор высоты при полной серии высот, иначе число точек. Исходная геометрия, старт/финиш и разрывы сегментов сохраняются.

GPX обрабатывается **в памяти браузера**: без отправки/сохранения маршрутов, аккаунтов и телеметрии. Используются локальные очертания карты. Исходный код проекта — **MIT**, сторонние лицензии/атрибуции сохранены.

- Приложение: https://matawaka.github.io/route-story/
- Репозиторий/README: https://github.com/Matawaka/route-story
- Release v1.0.0: https://github.com/Matawaka/route-story/releases/tag/v1.0.0
- Пример 16:9, Atlas 20s: https://github.com/Matawaka/route-story/releases/download/v1.0.0/atlas-20s.mp4
- Пример 9:16, Night 30s: https://github.com/Matawaka/route-story/releases/download/v1.0.0/night-30s.mp4
- GPX для повторения: https://github.com/Matawaka/route-story/releases/download/v1.0.0/synthetic.gpx
- Переход через 180°: https://github.com/Matawaka/route-story/releases/download/v1.0.0/synthetic-antimeridian.gpx

Примеры явно синтетические. Оба MP4 реально экспортированы из публичного HTTPS-приложения и независимо проверены FFmpeg/ffprobe; 480/720 кадров, 20/30 секунд, 24 FPS. Все публичные assets повторно скачаны и сверены по SHA-256.

Публичный экспорт проверен на Edge для Windows; локальная матрица также проверила конкретные desktop сборки Chrome и Playwright Firefox. H.264 зависит от кодировщика устройства. Физические Android/iOS и Safari **не проверены**; Playwright WebKit Windows сохраняет preview, но не предоставляет MP4-кодировщик в испытанной сборке.
