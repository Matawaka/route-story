# Воспроизводимая демонстрация Route Story

Публичный HTTPS URL: **PENDING — публикация требует разрешения владельца**. До публикации повторите те же действия локально после `npm.cmd ci`, `npm.cmd run build`, `npm.cmd run preview`. Адрес выводит Vite. Локальное прохождение не заменяет проверку публичного приложения.

Используйте только явно синтетические файлы: [synthetic.gpx](../public/samples/synthetic.gpx) (9 точек) и [synthetic-antimeridian.gpx](../public/samples/synthetic-antimeridian.gpx) (80 точек). Это настоящие GPX 1.1 с географическими координатами и высотой, но не реальные поездки/личная история. Сохраните Raw-файл с расширением `.gpx`; встроенная кнопка учебного примера загружает первый файл локально с сайта. Авторство синтетических данных — Route Story, MIT.

1. Откройте фактически опубликованный HTTPS URL без входа в GitHub; до публикации используйте localhost.
2. Выберите GPX-файл `synthetic.gpx`. Убедитесь, что появились исходная геометрия, старт/финиш, расстояние и набор высоты по данным GPX.
3. Выберите «Атлас».
4. Задайте название `Учебный маршрут · ATLAS`.
5. Выберите 20 секунд; шкала должна показывать время видео до 00:20, без утверждения о времени реальной поездки.
6. Запустите воспроизведение. Видны вступление, движение по исходному маршруту и финал.
7. Перемотайте на 10 секунд, затем назад на 3 секунды. Состояние маршрута должно соответствовать выбранному времени.
8. Выберите 16:9 и «Стандартное · 720p». При недоступном кодировщике прочитайте объяснение; выберите поддерживаемый браузер, не выдавайте ошибку за успешный экспорт.
9. Нажмите «Сохранить MP4». Покажите реальный прогресс, дождитесь сообщения об успешном создании файла.
10. Откройте скачанный MP4 в видеоплеере. Проверьте начало, движение и завершённый маршрут; итог — H.264, 1280×720, 20 секунд, 24 FPS, 480 кадров.
11. Повторите с `synthetic-antimeridian.gpx`, названием `Через 180° · синтетический маршрут`, стилем «Ночной», 30 секундами и форматом 9:16 Standard. Короткий переход через 180° должен сохранять геометрию; итог — 720×1280, 30 секунд, 720 кадров.

Для демонстрации восстановления запустите экспорт, нажмите «Отмена», затем повторите успешно. Повторный импорт должен заменить старый маршрут. После обновления страницы пользовательский GPX исчезает: он не сохраняется и не загружается на сервер.

Автоматизированный сценарий [release.mjs](../scripts/acceptance/release.mjs) выполняет эти действия через production UI, сохраняет два настоящих видео, проверяет их независимыми FFmpeg/ffprobe и открывает в native HTML video. Команды — [RELEASE.md](RELEASE.md). Сценарий не требует аккаунта, внешних GPS данных или искусственного экспортера.

Демонстрационные записи интерфейса, если сделаны позднее, дополняют работающий сайт. В этом checkpoint запись экрана не создана и конкурсная заявка не отправлена.
