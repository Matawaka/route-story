# Длительность сцены с телефона

Кандидат `codex/mobile-duration-controls` от опубликованного main `d91361816396905e44fff8bcbe7ac058b304fee3`. Базовая версия пакета остаётся 1.7.0; эта доработка пока не опубликована.

В редакторе появились кнопки «−1 с» / «+1 с» с областью нажатия не менее 44 px. Они применяют изменение сразу к видимому числу: например, ввод 7,5 и «+1 с» дают 8,5 с. Ручной ввод применяется через «Изменить время». Время округляется до кадров 24 FPS; общий хронометраж сохраняется за счёт остальных сцен маршрута.

Допустимость определяет прежняя модель `editDuration`: минимум один кадр, обзор/финал до 3 с, остальные сцены маршрута сохраняют положительное время. Если сцена маршрута одна, её время меняется общей длительностью ролика или временем обзора/финала. Пустые и недопустимые значения блокируют действие и показывают причину. Повторное применение того же кадра отключено: оно не перераспределяет соседние сцены и не добавляет запись Undo. Поле корректно принимает отображаемый минимум 0,04 с. Подготовка и экспорт блокируют новые кнопки.

Каждое изменение проходит существующую проверку камеры и историю Undo/Redo. Модель монтажа, GPX, схема `.rstory.json`, renderer, общий clock, encoder, зависимости, ресурсы и лимиты не изменены. Синтетическая Фурка — единственный маршрут нового сценария.

## Проверка

Расширен существующий `tests/e2e/mobile-editor.spec.ts`: дробный ввод и обе кнопки, точный Undo/Redo, общая сумма кадров, пустое/неверное/повторное значение, один кадр, предел обзора, единственная сцена маршрута, размеры 320/390/428 и 844×390, блокировка экспорта. Сохранены проверки реального touch-таймлайна, покадровых пикселей, обоих форматов, сохранения/открытия проекта и настоящего 20-секундного H.264 MP4. Запись и скриншоты создаёт настоящий браузер.

```sh
npm ci
npm run check
STORYBOARD_ACCEPTANCE=1 MOBILE_EDITOR_ACCEPTANCE=1 UNIFIED_UX_ACCEPTANCE=1 PLAYWRIGHT_CHANNEL=msedge npx playwright test tests/e2e/storyboard.spec.ts tests/e2e/mobile-editor.spec.ts
BUILD_COMMIT=$(git rev-parse HEAD) node scripts/acceptance/editor-package.mjs
```

Windows: переменные задаются через `$env:…`; команды — `npm.cmd` / `npx.cmd`. Существующий read-only `mobile-editor.yml` выполняет браузерную приёмку, независимый FFmpeg/ffprobe и проверку полных пакетов 5/6/9 MiB.

На первом контрольном пункте Node24 `node --check src/storyboard-editor.ts` и `node --check tests/e2e/mobile-editor.spec.ts` — PASS только синтаксиса. TypeScript, unit, браузер, MP4 и размеры нового кандидата ожидают точный CI; прежняя публикация не доказывает новый код. Локальная среда не предоставляет установленные зависимости и браузер, поэтому рабочие проверки выполняются в существующем Windows/Edge CI.

Физические iOS/Android, нативные клавиатура/пикер/поворот, общий GPU/native memory и новые FullHD/4K-сценарии НЕ ПРОВЕРЕНЫ. Новое слияние/публикация/Release/tag/защищённые настройки этим кандидатом не выполняются.
