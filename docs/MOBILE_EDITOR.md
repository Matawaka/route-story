## Управление

- Стрелки рядом со счётчиком выбирают предыдущую или следующую сцену. Показаны её номер и временной интервал; на краях лишняя стрелка отключена.
- Выбор сцены останавливает replay и показывает её начало. Лента прокручивается по горизонтали до выбранной карточки; страница при этом не прыгает. Ручная прокрутка не сбрасывается при постороннем обновлении UI.
- На клавиатуре Tab приводит к выбранной карточке, стрелки перемещают выбор, Home/End открывают первую/последнюю сцену.
- Кнопки и перемотка имеют область нажатия не менее 44 px. Поля имеют шрифт 16 px, чтобы Safari не увеличивал страницу при вводе. Это настройка интерфейса, а не подтверждение физического Safari.
- Ссылки «Настройки и маршрут» / «К видео и монтажу» позволяют быстро переходить между картой и настройками. На широком экране с точным указателем сохраняются две колонки; для сенсорного экрана до 1100 px применяется мобильная компоновка, включая поворот телефона.
- Устаревший асинхронный подбор ракурсов отменяется при следующем выборе сцены. Последовательность A → B → A не должна добавлять повторные варианты из первой операции.
- В выбранной сцене есть отдельная перемотка с шагом в один кадр, номером кадра и временем в полном видео. Home/End выбирают её первый/последний кадр; ползунок не выходит в соседнюю сцену. Общий ползунок принимает точные секунды без округления до 0,01 с, чтобы не сдвигать метки 24 FPS.
- «Показать выбранный кадр» ставит просмотр на паузу и на телефоне поднимает к видео. «Только этот эпизод» открывает там же проигрывание до последнего кадра сцены, без кадра следующей. Ссылка «К монтажу» возвращает к редактору; она видна только пока монтаж открыт. Сам выбор карточки страницу не прокручивает.
- Шкала «Весь монтаж» показывает пропорции всех сцен, включая вступление, финал и акценты. Касание или клавиатура выбирают кадр и соответствующую сцену, ставят replay на паузу; выбранная карточка становится видна без вертикального прыжка. Home/End остаются в пределах реальных кадров видео. Ползунок следует за общим просмотром.
- «← Кадр» / «Кадр →» сдвигают выбранный кадр ровно на 1/24 с. На первом и последнем кадре сцены лишняя кнопка отключена; во время подготовки и экспорта обе кнопки и общая шкала блокируются. Шкала обновляется после изменения времени, Undo/Redo и открытия проекта. Полная последовательность кадров не кэшируется.

Renderer, непрерывная проверка камеры, GPX, схема `.rstory.json`, длительности и кодировщик не меняются. Новых зависимостей, географических ресурсов и разрешений нет. Проект по-прежнему не содержит GPX/координат; данные остаются в памяти.

## Воспроизведение приёмки

```sh
npm ci
npm run check
STORYBOARD_ACCEPTANCE=1 MOBILE_EDITOR_ACCEPTANCE=1 UNIFIED_UX_ACCEPTANCE=1 PLAYWRIGHT_CHANNEL=msedge npx playwright test tests/e2e/storyboard.spec.ts tests/e2e/mobile-editor.spec.ts
BUILD_COMMIT=$(git rev-parse HEAD) node scripts/acceptance/editor-package.mjs
```

В Windows задайте переменные через `$env:…='1'` и используйте `npm.cmd`/`npx.cmd`. Отдельный workflow `mobile-editor.yml` повторяет эти проверки с закреплёнными actions и правами только на чтение. Существующий защищённый Pages workflow не меняется.

Сценарий проверяет настоящий UI синтетической Фурки: touch-навигацию, быстрые события A → B → A без подмены renderer/proof, отсутствие дубликатов ракурсов, сохранность ввода, Undo/Redo, клавиатуру, размеры 320/390/428 и поворот 844×390, оба формата видео, переходы к настройкам, сохранение и открытие проекта с точными пикселями. Проверяются пропорциональные ширины сцен после изменения времени, Undo/Redo и project reload; реальное касание общей шкалы с паузой и выбором сцены без вертикального прыжка; шаг кнопок ровно 1/24 с и обратное совпадение пикселей, блокировка на границах, scene/global seek, Home/End, фактическое завершение проигрывания на последнем кадре и preview/return. Начало воспроизведения фиксируется до касания через наблюдение реального DOM-перехода, чтобы задержка удалённого чтения не пропустила PLAYING; конечные кадр/время/пиксели и прежние таймауты сохранены. Создаётся настоящий отредактированный портретный 20-секундный H.264 MP4 с независимым FFmpeg/ffprobe декодированием всех 480 кадров. Во время экспорта навигация и перемотка сцены блокируются. Отдельно сохраняются три настоящих скриншота и запись браузера. Из скачанного полного видео сделан локальный непрерывный 28-секундный фрагмент (35–63 с исходной записи), 390×844/15 FPS/H.264/470 263 Б, полностью декодирован; это только обрезка и перекодирование настоящего UI, без дорисовки. Полный исходник доступен в архиве записи; SHA/параметры фрагмента в машинном отчёте. Пакеты baseline/Sogne/combined проверяются прежним packager в пределах 5/6/9 МиБ.
